## Selected work


### Convertly
**Product direction, architecture & implementation**


A creator campaign management platform connecting brand workspaces, campaign workflows, creator portals, storefronts and commissions.


**Status:** Paused product; available for a private demonstration. Source code is private.


[Watch the 2:51 product walkthrough →](https://www.youtube.com/watch?v=1u17CTt2UTU)


<details>
<summary>Three engineering decisions behind the product</summary>


- **Verify incoming events.** Shopify webhook signatures are checked against the raw request body before processing.
- **Keep financial state changes together.** The commission-approval path conditionally claims a pending record and writes its ledger entry in the same transaction, avoiding a second approval entry from a competing worker.
- **Keep consequential AI actions behind confirmation.** The server controls automatic actions; invitations, messages and rewards require human confirmation.


These describe implemented controls, not a claim of customer traction or a comprehensive security audit.


</details>
